# TAESD Latent-Space Image Steganography

A deep learning-based image steganography system using **TAESD (Tiny AutoEncoder for Stable Diffusion)**, latent-space message embedding, and perceptual loss functions.

This project was developed during my research internship at the **Computational Light Laboratory, University College London (UCL)**, under the supervision of **Assoc. Prof. Kaan Akşit**, between July 20 and August 14, 2026.

The project investigates how different perceptual loss functions affect the trade-off between **message recovery accuracy** and **image quality**.

Four models were developed and compared:

- Baseline (Cross-Entropy + MSE)
- LPIPS
- FLIP
- ColorVideoVDP

All four models use the same network architecture. The primary difference is the loss function used during training.

---

## 1. Project Overview

Image steganography is the process of hiding information inside an image without making the hidden information visually obvious.

Traditional methods, such as Least Significant Bit (LSB) replacement, directly modify pixel values. In contrast, this project uses a neural network to embed information into the latent representation of an image.

The system is designed to:

1. Encode an RGB image into a latent representation using TAESD.
2. Embed an ASCII character into this latent representation.
3. Decode the modified latent representation into a stego image.
4. Recover the embedded character using a message extraction network.
5. Evaluate message recovery and image quality.

The system supports **256 ASCII classes (0–255)**, representing one character or byte value per image.

The main research question is:

**Can perceptual loss functions improve image quality while maintaining accurate message recovery in latent-space image steganography?**

## 2. System Architecture

The system consists of three main components:

1. TAESD Encoder–Decoder
2. LatentEmbedder
3. MessageExtractor

### Overall Pipeline

```text
Original RGB Image (64×64)
          |
          v
 Resize to 512×512
          |
          v
   TAESD Encoder
          |
          v
    Clean Latent z  <-------- ASCII Message
          |                       |
          |                       v
          |                 Message Features
          |                       |
          +-----------+-----------+
                      |
                      v
                LatentEmbedder
                      |
                      v
              Latent Change Δz
                      |
                      v
              Stego Latent z+Δz
                      |
                      v
                TAESD Decoder
                      |
                      v
                Stego Image
                      |
                      v
                Resize to 64×64
                      |
                      v
               MessageExtractor
                      |
                      v
             Recovered ASCII Class
```

The pretrained TAESD encoder and decoder remain frozen during training.

Only the LatentEmbedder and MessageExtractor are trained.

### 2.1. TAESD Encoder–Decoder

TAESD is a lightweight pretrained autoencoder designed for Stable Diffusion.

It consists of:

- An encoder that transforms images into latent representations.
- A decoder that reconstructs images from latent representations.

In this project, the input images have a resolution of 64×64 pixels.

Before encoding, each image is resized to 512×512 pixels.

The encoded representation has a spatial resolution of 64×64.

The TAESD decoder reconstructs the image from this representation. The resulting image is resized back to 64×64 pixels.

The resizing strategy was selected based on preliminary reconstruction experiments.

The TAESD weights are kept frozen to focus training on message embedding and extraction.

Official TAESD repository:

https://github.com/madebyollin/taesd

### 2.2. LatentEmbedder

The `LatentEmbedder` is a neural network developed to insert message information into the image's latent representation.

It receives two inputs:

- The clean latent representation generated by TAESD.
- An integer message class between 0 and 255.

First, the message is converted into a learnable embedding vector.

```python
nn.Embedding(256, 128)
```

This layer learns a 128-dimensional representation for each possible message class.

The embedding is projected into a spatial feature representation using a linear layer.

```python
nn.Linear(128, 256 * 8 * 8)
```

The resulting features are reshaped and progressively upsampled using transposed convolutional layers.

The message representation is transformed into a feature map with a spatial resolution of 64×64.

The message features are then concatenated with the clean image latent along the channel dimension.

Additional convolutional layers process the combined representation and generate a message-dependent latent modification.

The modification is bounded using the hyperbolic tangent function:

```python
delta = torch.tanh(raw_delta) * max_delta
```

The modified latent representation is calculated as:

```python
stego_latent = clean_latent + delta
```

The `max_delta` parameter limits the magnitude of the modification.

It is calculated from the standard deviation of clean latent representations obtained from the training images.

```python
DELTA_SCALE = 0.10

MAX_DELTA = DELTA_SCALE * LATENT_STD
```

This constraint helps prevent excessively large changes to the reconstructed image.

### 2.3. MessageExtractor

The `MessageExtractor` is a convolutional neural network designed to recover the hidden message from the stego image.

It receives a 64×64 RGB stego image.

The network contains convolutional layers, Group Normalization, ReLU activations, adaptive average pooling, and a final linear classification layer.

Its general structure is:

```text
Stego Image (3×64×64)
          |
          v
   Convolution (32)
          |
     GroupNorm + ReLU
          |
          v
   Convolution (64)
          |
     GroupNorm + ReLU
          |
          v
   Convolution (128)
          |
     GroupNorm + ReLU
          |
          v
   Convolution (256)
          |
     GroupNorm + ReLU
          |
          v
  Adaptive Average Pooling
          |
          v
      Linear Layer
          |
          v
      256 Class Scores
          |
          v
      Predicted ASCII
```

The network produces 256 classification scores.

The class with the highest score is selected as the recovered message.

```python
predicted_message = logits.argmax(dim=1)
```

Cross-entropy loss is used to train the message extraction process.

## 4. Dataset and Preprocessing

The experiments use a subset of the **Tiny ImageNet dataset**.

Tiny ImageNet contains RGB images with a resolution of 64×64 pixels.

The experimental setup includes:

- 100 training images.
- 20 validation images.
- Separate unseen images for testing.

All images are converted into RGB format and PyTorch tensors.

### Image Processing

The image is resized from 64×64 to 512×512 pixels before being passed into TAESD.

After decoding, the image is resized back to 64×64 pixels.

```text
64×64
  |
  v
512×512
  |
  v
TAESD Encoder
  |
  v
Latent Representation
  |
  v
TAESD Decoder
  |
  v
512×512
  |
  v
64×64
```

### Preliminary Reconstruction Experiments

Three strategies were investigated to determine an appropriate TAESD input resolution.

| Method | TAESD Input | PSNR | SSIM |
|---|---|---|---|
| 16-image collage | 256×256 | 17.27 dB | 0.4018 |
| Individual resizing | 256×256 | 26.08 dB | 0.8894 |
| Individual resizing | 512×512 | 31.11 dB | 0.9705 |

The 512×512 resizing strategy produced the best reconstruction results among the tested methods.

Therefore, this processing method was used in the subsequent steganography experiments.

## 5. Training Configuration

The same general training procedure was used across the four models.

The pretrained TAESD encoder and decoder were frozen.

The LatentEmbedder and MessageExtractor were trained jointly.

### Main Training Settings

| Parameter | Value |
|---|---|
| Training images | 100 |
| ASCII classes | 256 |
| Samples per ASCII class per epoch | 4 |
| Image-message pairs per epoch | 1,024 |
| Training epochs | 75 |
| Batch size | 16 |
| Optimizer | AdamW |
| Learning rate | 0.001 |
| Weight decay | 0.00001 |
| Delta scale | 0.10 |
| Scheduler | CosineAnnealingLR |
| Random seed | 42 |
| TAESD | Frozen |

### Training Procedure

During each epoch, all 256 ASCII classes are used four times.

This produces 1,024 image-message pairs.

The message classes are shuffled and paired with randomly selected training images.

For each batch:

1. The images are encoded using TAESD.
2. Clean reconstructed images are generated.
3. The LatentEmbedder inserts the message information.
4. The modified latent representations are decoded into stego images.
5. The MessageExtractor predicts the hidden ASCII classes.
6. Classification and image-quality losses are calculated.
7. Backpropagation updates the two trainable networks.

The TAESD parameters remain unchanged.

### Optimizer and Scheduler

AdamW is used to optimize the trainable networks.

The learning rate is initially set to:

```python
LEARNING_RATE = 0.001
```

Cosine annealing gradually reduces the learning rate during training.

The training notebooks also include checkpoint-saving functionality.

## 6. Loss Functions

The central objective of the project is to balance:

- Message recovery accuracy.
- Image similarity.
- Perceptual image quality.

All four models use cross-entropy loss for message classification and MSE for pixel-level image similarity.

The perceptually guided models include one additional perceptual loss.

### 6.1. Baseline Model

The baseline model uses two loss components.

**Cross-Entropy Loss**

Measures the difference between the actual embedded ASCII class and the class predicted by the MessageExtractor.

**Mean Squared Error (MSE)**

Measures the pixel-level difference between the clean TAESD reconstruction and the stego image.

The baseline objective is:

```python
total_loss = class_loss + 0.1 * image_loss
```

The baseline serves as the reference model for evaluating the impact of perceptual loss functions.

### 6.2. LPIPS Model

LPIPS stands for **Learned Perceptual Image Patch Similarity**.

It evaluates image similarity using features extracted by a pretrained neural network.

Unlike MSE, LPIPS considers differences in learned image features.

The experiment uses an AlexNet-based LPIPS model.

Before calculating LPIPS, the images are converted from the range [0, 1] to [-1, 1].

```python
lpips_loss = lpips_loss_fn(
    stego_64 * 2 - 1,
    clean_recon_64 * 2 - 1
).mean()
```

The LPIPS term is added to the baseline objective:

```python
total_loss = (
    class_loss
    + 0.1 * image_loss
    + 10.0 * lpips_loss
)
```

**LPIPS coefficient: 10.0**

The purpose of this model is to investigate whether learned perceptual features can improve visual similarity while maintaining message recovery accuracy.

### 6.3. FLIP Model

FLIP is a perceptual difference metric designed to evaluate visually noticeable differences between images.

It considers image features and color differences.

The project uses NVIDIA's `LDRFLIPLoss` implementation.

```python
flip_loss = flip_loss_fn(
    stego_64,
    clean_recon_64
)
```

The total loss becomes:

```python
total_loss = (
    class_loss
    + 0.1 * image_loss
    + 0.01 * flip_loss
)
```

**FLIP coefficient: 0.01**

This model investigates whether FLIP-based supervision improves image quality without significantly reducing the ability to recover hidden messages.

Official FLIP repository:

https://github.com/NVlabs/flip

### 6.4. ColorVideoVDP Model

ColorVideoVDP is a perceptual model designed to predict visible image and video differences.

It incorporates characteristics of the human visual system, including:

- Color perception.
- Contrast sensitivity.
- Spatial detail.
- Viewing and display conditions.

The ColorVideoVDP loss is calculated between the clean reconstructed image and the stego image.

The training objective is:

```python
total_loss = (
    class_loss
    + 0.1 * image_loss
    + 0.1 * cvvdp_loss
)
```

**ColorVideoVDP coefficient: 0.1**

**Batch size: 16**

The model uses ColorVideoVDP-based perceptual supervision to investigate whether visibility-oriented image differences can be reduced during message embedding.

Official ColorVideoVDP repository:

https://github.com/gfxdisp/ColorVideoVDP

### Summary of Loss Functions

| Model | Classification | MSE | Additional Perceptual Loss |
|---|---|---|---|
| Baseline | 1.0 | 0.1 | None |
| LPIPS | 1.0 | 0.1 | LPIPS × 10.0 |
| FLIP | 1.0 | 0.1 | FLIP × 0.01 |
| ColorVideoVDP | 1.0 | 0.1 | ColorVideoVDP × 0.1 |

The same main architecture was used for all experiments.

The differences in the training objectives allow the effects of perceptual guidance to be investigated.

## 7. Checkpoint Selection

Each model was trained for 75 epochs.

During training, checkpoints were saved to preserve model states.

The evaluation procedure considered two main checkpoint candidates:

1. The checkpoint with the highest training message-recovery accuracy.
2. The checkpoint saved at the end of epoch 75.

After training, both candidate checkpoints were evaluated on the same validation set.

The checkpoint with the higher validation message-recovery accuracy was selected.

If both checkpoints achieved equal validation accuracy, the checkpoint with the lower corresponding image/perceptual metric was preferred.

The selected checkpoints were used in the final evaluation.

### Selected Checkpoints

| Model | Selected Epoch | Validation Accuracy |
|---|---|---|
| Baseline | 75 | 88.20% |
| LPIPS | 75 | 89.38% |
| FLIP | 73 | 93.05% |
| ColorVideoVDP | 68 | 92.81% |

These results were used for checkpoint selection before evaluation on unseen test images.

## 8. Evaluation Metrics

The trained models were evaluated in terms of both message recovery and image quality.

Five metrics were included in the final test.

### 8.1. Message Recovery Accuracy

Message accuracy measures the percentage of correctly recovered ASCII classes.

```text
Accuracy = Correct Predictions / Total Predictions × 100
```

Higher accuracy indicates better message recovery.

### 8.2. Peak Signal-to-Noise Ratio (PSNR)

PSNR measures pixel-level image similarity.

The main PSNR evaluation compares the stego image with the clean TAESD reconstruction.

Higher PSNR indicates smaller pixel-level differences.

### 8.3. Structural Similarity Index (SSIM)

SSIM measures structural similarity between images.

The clean TAESD reconstruction is used as the reference.

SSIM values closer to 1 indicate greater structural similarity.

### 8.4. End-to-End PSNR

End-to-end PSNR compares the final stego image directly with the original input image.

Unlike the main PSNR metric, this includes both:

- Image changes introduced by TAESD reconstruction.
- Additional changes introduced by message embedding.

This metric provides a broader view of overall image preservation.

### 8.5. LPIPS

LPIPS measures perceptual differences using features extracted by a pretrained neural network.

The final-test LPIPS metric compares the stego image with the clean TAESD reconstruction.

Lower LPIPS values indicate greater perceptual similarity under this metric.

## 9. Final Testing Procedure

The final comparison was conducted using an independent test set.

The test included:

- 100 unseen images.
- 64 ASCII classes per image.
- 6,400 image-message pairs for each model.

The same images and message classes were used across all four models.

This provides a consistent comparison between the different training objectives.

### Reproducibility Settings

The final test uses fixed random seeds.

```python
SEED = 42
SPLIT_SEED = 2026
MESSAGE_SEED = 2027

N_IMAGES = 100
MESSAGES_PER_IMAGE = 64
BATCH_SIZE = 16
```

The test process is:

1. Load the pretrained TAESD encoder and decoder.
2. Load the selected checkpoint for each model.
3. Select the test images using the fixed split seed.
4. Generate ASCII test messages using the fixed message seed.
5. Embed each message into the corresponding image.
6. Decode the resulting stego image.
7. Recover the embedded ASCII class.
8. Calculate message accuracy and the four image-quality metrics.
9. Compare the results across the four models.

The evaluation notebook uses the already trained checkpoints and does not retrain the models.

### 10.2. Final Test Results

The following results were obtained from the selected models using the independent 100-image test set.

| Model | Epoch | Message Accuracy | PSNR | SSIM | End-to-end PSNR | LPIPS |
|---|---|---|---|---|---|---|
| Baseline | 75 | 88.64% | 31.28 dB | 0.9206 | 24.83 dB | 0.0337 |
| LPIPS | 75 | 89.72% | 39.27 dB | 0.9875 | 25.68 dB | 0.0029 |
| FLIP | 73 | 87.23% | 31.42 dB | 0.9319 | 24.92 dB | 0.0209 |
| **ColorVideoVDP** | **68** | **95.80%** | **39.76 dB** | **0.9891** | **25.70 dB** | **0.0026** |

### 10.3. Discussion

The results demonstrate different trade-offs between message recovery and image quality.

**Baseline**

The baseline achieved 88.64% message recovery accuracy.

However, its image-quality metrics were lower than those of the strongest perceptually guided models.

**LPIPS**

LPIPS improved image similarity substantially compared with the baseline.

It achieved:

- 89.72% message accuracy.
- 39.27 dB PSNR.
- 0.9875 SSIM.
- 0.0029 LPIPS.

This indicates that LPIPS-based training improved image preservation while maintaining message recovery performance.

**FLIP**

FLIP achieved 87.23% message accuracy.

Its image-quality scores showed more limited improvements compared with the baseline.

The FLIP model did not provide a clear overall advantage under the selected training conditions.

**ColorVideoVDP**

ColorVideoVDP achieved the strongest overall numerical results.

It produced:

- 95.80% message accuracy.
- 39.76 dB PSNR.
- 0.9891 SSIM.
- 25.70 dB end-to-end PSNR.
- 0.0026 LPIPS.

Under the tested conditions, ColorVideoVDP provided the best balance between message recovery and image similarity among the four models.

These findings suggest that the choice and weighting of perceptual loss functions can significantly affect steganographic model performance.

## 11. Visual Evaluation

Visual comparisons were also performed to examine the effects of message embedding.

For each model, the following images can be compared:

1. Original image.
2. Clean TAESD reconstruction.
3. Stego image.
4. Amplified absolute-difference image.

The clean reconstruction is generated without embedding a message.

The stego image is generated after adding the message-dependent latent modification.

The difference image helps reveal changes that may not be immediately visible when viewing the images normally.

Visual evaluation complements the numerical metrics.

A visually similar image does not necessarily imply perfect message recovery, and high recovery accuracy does not necessarily guarantee strong perceptual quality.

## 14. Reproducibility Notes

The notebooks use fixed random seeds to make the experimental setup more consistent.

However, reproducing the exact results also requires:

- The same image dataset.
- The same train/validation/test partitions.
- The same model checkpoints.
- The same selected training configurations.
- Compatible library versions and execution settings.

A checkpoint file must correspond to the intended trained model.

Checkpoint filenames may contain labels inherited from earlier experimental configurations, so the actual weights and training settings should be checked when reproducing a run.

The project evaluates image quality relative to clean TAESD reconstruction for PSNR, SSIM, and LPIPS.

End-to-end PSNR instead uses the original input image.

These reference images should not be confused when interpreting the results.

## 15. Limitations and Future Work

The current system is a research prototype.

It supports one ASCII class per image and has been evaluated using a relatively limited image dataset.

Although the experiments measure message recovery and image similarity, they do not establish that the hidden messages are undetectable by steganalysis tools.

Possible future developments include:

- Embedding longer messages instead of single ASCII classes.
- Testing larger and more diverse image datasets.
- Evaluating robustness to compression and image transformations.
- Investigating steganalysis-based detectability.
- Exploring additional perceptual loss functions.
- Performing further studies of human visual perception and image quality.

The results demonstrate the potential of perceptually guided latent-space message embedding, but further evaluation is necessary before drawing broader conclusions about robustness or security.
