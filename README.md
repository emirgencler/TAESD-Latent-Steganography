# TAESD Latent Steganography

This repository contains experimental implementations of latent-space image steganography using TAESD and PyTorch.

## Overview

The notebook explores embedding information directly into the latent representations produced by TAESD. Different experiments were conducted to evaluate reconstruction quality and message embedding performance.

## Technologies

- Python
- PyTorch
- TAESD
- TorchMetrics

## Status

This repository contains research experiments and is intended for educational and research purposes.
